# 开发和验证

## 构建与安装包

在 `plugins/luckin/` 执行：

```bash
pnpm install --frozen-lockfile
pnpm check
```

`pnpm check` 先运行 Node 模拟测试，再用现有 esbuild 构建 `dist/server.mjs`，最后重新生成 `release/luckin/`。发布目录包括清单、许可证、技能、资源、运行文件与整个 `ui/` 目录。`shared.js` 在服务器读取资源时嵌入两份 HTML，资源 URI 按完整内容计算哈希；源码与安装包都必须保留共享文件。没有新增运行依赖。

安装者无需构建。更新本地安装副本需在仓库根目录执行 `codex plugin add luckin@luckin-community`，然后重启 Codex 并重新打开应用；不能直接修改插件缓存。当前任务只更新仓库与预构建包，没有替换已安装插件。

回到仓库根目录运行 `git diff --check`，检查清单、相对文档链接、构建产物和工作区状态。真实 Token、订单号、位置、支付链接、截图和请求日志均不能进入 Git。
